# 告知：予約システム／相談チャット（2026-08-07）

CEO指摘(2026-08-07)「予約機能も告知してない」。
予約(§17-1)と相談(§16-19)は**同じ導線の前半と後半**なので、1本にまとめて出す。
分けて出すと「相談したあと予約にどうつなぐか」が伝わらない。

配信は admin dashboard ＞ お知らせ管理／一斉送信から。LINE優先。
送信後は `broadcast_logs` で1バッチ・1人1件を検証する（過去に対象数のズレの前例あり）。

## ③ メール

**件名**: 予約と相談が、REAL PROOFの中で完結するようになりました

いつもREAL PROOFをご利用いただきありがとうございます。
あなたのカードに「**予約する**」と「**相談する**」が付きました。

### 予約：サイトが無くても、今日から受けられます

これまでは、予約導線を持っている先生しかカードから予約を受けられませんでした。
**REAL PROOFの予約フォームを使えば、予約サイトが無くても今日から受けられます。**

- ご自分の予約サイトをお持ちの先生は、**どちらを使うか選べます**（今の運用は変わりません）
- **メニューからも直接予約できます。** 金額が見えた状態で進めるので、あとから聞き直す手間がありません
- **予約金はかかりません。** お客さまは当日おいでになるだけです
- 届いた予約はダッシュボードの「**予約**」タブに入ります

### 相談：予約の前に、一度話せます

「気になるけれど、いきなり予約するのは…」というお客さんが、そのまま離れていく代わりに、
一言聞けるようになりました。実際に多いのは
「自分の症状でも大丈夫ですか」「どのメニューが合いますか」です。

- 届いた相談は「**相談**」タブへ。返信を書くとお客さんにメールで届きます
- お客さまは**アカウント登録なしで**、メールのリンクから続けて返信できます

### 相談から予約へ、そのままつながります

話がまとまったら、チャットから**メニューを提案**できます。
お客さまはボタン1つで予約フォームに進めます。ここが今回いちばん効くところです。

自分の専門から外れる相談は、**紹介リストをその場で送れます**。
断って終わりにせず、適した先生におつなぎできます。

### 受けたくない時期はオフにできます

予約と相談は**別々のスイッチ**です。「予約は受けたいが相談はしたくない」も設定できます。

▶ ダッシュボードを開く
https://realproof.jp/dashboard?tab=bookings
